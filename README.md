# 🧠 Disease Prediction from Medical Data

## 📌 Overview
This project uses Machine Learning to predict multiple diseases based on patient medical data.

We built predictive models for:
- 🫀 Heart Disease
- 🩸 Diabetes
- 🎗 Breast Cancer

---

## 🚀 Data sets Used
- /kaggle/input/datasets/alaahussien/breast-canser
- /kaggle/input/datasets/fedesoriano/heart-failure-prediction
- /kaggle/input/datasets/organizations/uciml/pima-indians-diabetes-database

---

---

## 🚀 Machine Learning Models Used
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

---

## 📊 Workflow
1. Data Collection (UCI datasets)
2. Data Cleaning & Preprocessing
3. Feature Encoding & Scaling
4. Model Training
5. Evaluation & Comparison
6. Model Saving (.pkl files)
7. Feature Importance Analysis

---

## 🧠 Key Insights
- Heart disease is strongly influenced by chest pain type and ST slope
- Glucose level is the strongest predictor for diabetes
- Tumor size is critical for breast cancer prediction
